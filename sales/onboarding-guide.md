# LeadBridge — Onboarding Guide (1 Page, Hinglish)

> Goal: get a new broker from "signed up" to "first AI call handled" in under 30 minutes.
> Keep this 1 page. Brokers are busy — make it scannable.

---

## 👋 Welcome to LeadBridge!

Aapka AI agent ab aapki jagah calls uthayega — 5 second mein, 24×7, Sunday–holiday sab kuch.
Bas ye 5 steps karo aur sab set hai. (Screenshot references = dashboard left sidebar.)

---

## Step 1 — Apna Area Set Karo (Territory)

**Dashboard → Settings → Territory** (ya signup ke waqt)

- Apna **city + zone** daalo (e.g. "Mumbai, Andheri West").
- Ye aapka **service area** hai — isi area ke leads aapke scoring mein priority paate hain.
- LeadBridge aapke area mein doosra broker onboard nahi karega (exclusivity agreement ke hisaab se).

---

## Step 2 — AI Agent Banao (2 minutes)

**Dashboard → Voice AI → "New Agent"**

- **Agent name:** e.g. "Property Assistant" (jo bhi professional lage)
- **Language:** Hinglish (recommended) — Hindi / English bhi options hain
- **Instructions:** batao agent ko kaise behave karna hai, kya poochna hai
  (e.g. "Buyer ko budget, area, timeline, property type poocho. Apna intro do. Visit book karne ke liye ready raho.")
- **Create Agent** dabao → agent ban jaayega aur assign ho jaayega

---

## Step 3 — Number Lo Aur Attach Karo (5 minutes)

**Voice AI → "Buy Number"**

- Region: India → **Buy Number** (₹200/month rental, platform handles it)
- Ya aapka apna number hai? **Import** karo (Exotel / Twilio supported)
- Number aate hi **"Attach to Agent"** dabao

> Jab number attached ho, banner green ho jaata hai: **"Your AI calling system is live"**

---

## Step 4 — Test Call Karo (2 minutes)

**Voice AI → "Test Call"**

- Aapka phone 30 second mein bajega — AI agent baat karega.
- Agar achha lage toh bolna! (Isi call ki recording bhi milegi.)

---

## Step 5 — Leads Aane Ke Raste Kholo

Leads 4 raste se aate hain — jitne kholo, utna badhiya:

### A. Portal SMS Forwarding (recommended — sabse easy)
**Dashboard → Lead Forwarding**

- Android: SMS kholo → long-press → **Forward** → LeadBridge number (screen par dikhta hai) → Send
- iPhone: message bubble par tap-hold → **More…** → forward arrow → LeadBridge number → Send
- **99acres, MagicBricks, Housing.com, JustDial — sab ka SMS kaam karta hai, format kuch bhi ho.**

### B. Portal Email Forwarding
**Lead Forwarding → Forwarding Email**
- Portal enquiry email → **Forward** → LeadBridge email par bhejo
- (Automatic forwarding ke liye SendGrid/Mailgun setup support se kara lo)

### C. Google Sheets (aapka existing list)
**Dashboard → Integrations → Google Sheets** — 2-way sync, har 15 min

### D. CSV Import
**Dashboard → Leads → Import CSV** — purani list ek baar mein daal lo

---

## Bonus — Agent Ko Gyaan Do (Knowledge Base)

**Voice AI → Knowledge Base → Upload PDF**

- Apne properties / brochures ke PDFs upload karo — agent buyer ke sawaalon ke
  jawab aapke hi inventory se dega.

---

## ✅ Done! Ab Kya Hota Hai Jab Lead Aata Hai?

1. Lead aata hai (SMS/email/sheet/CSV) → system **5 second mein parse** karta hai
   (naam, phone, budget, area, property type)
2. Lead **scored** hota hai (seriousness) + aapke inventory se match
3. **AI agent call karta hai** turant — ya agar buyer aapko call kare, toh agent uthata hai
4. Call → **transcript + AI summary** (budget, timeline, next step) — aap recording sunne ki zaroorat nahi
5. **Site visit book** → aapke calendar + Google Calendar par, reminders ke saath
6. **WhatsApp/SMS follow-ups** — day 2, day 7, visit se pehle/baad — koi lead thanda nahi padta
7. **Dashboard par sab dikhta hai** — leads, calls, bookings, ROI

## Kuch Zaroori Baatein

- **Aapka plan:** Starter ₹18K (100 calls/mo) · Growth ₹35K (500 calls/mo) · Pro ₹60K
  — flat fee, koi per-minute charge nahi. Number, agent, WhatsApp+SMS, recordings,
  transcripts, analytics — sab included.
- **Calls use hote hi count hota hai** — unused calls agle mahine roll over hote hain
  (max 3 mahine tak).
- **Koi problem?** Support WhatsApp/email par message karo — response time promise
  dekhne ke liye support-channel.md.
